## 赛题背景与目标

本系统针对 **VAST Challenge 2020 Mini-Challenge 2 (MC2)** 的复杂社交网络背景开发。故事背景中，Center for Global Cyber Strategy (CGCS) 发现有一组人在使用某种秘密“暗号（Totem）”在图像和社交媒体文本中进行隐蔽通信。

官方提供了一组包含了原始社交文本、图片以及 **YOLO 模型的目标检测结果（预测标签与置信度）**的数据。我们的核心任务是：从极其杂乱、且充满大量机器误报的预测数据中，揪出一个确切的 **8人嫌疑子群体**，并查明他们用于秘密通信的确切暗号。

赛题要求通过可视分析手段回答以下 **5 个核心问题（Q1 - Q5）**：
- **Q1 (模型评估)**：提供的物体检测器表现如何？有哪些优势和劣势？
- **Q2 (数据校正)**：如何通过可视化工具与人工介入来纠正分类器的错误？
- **Q3 (特征分布)**：人物与提取出的物品特征之间存在怎样的对应关系？
- **Q4 (暗号识别)**：如何锁定真正的“通信暗号”，并找出这 8 人通信小组？
- **Q5 (关系网络)**：该小组是如何利用暗号进行信息交换的？

## 分析思路：从原始杂讯到锁定 8 名嫌疑人的完整过程

本系统并非单纯地把图表堆砌在一起，而是提供了一套**层层递进、逻辑闭环**的可视化刑侦流水线。任何人按照以下步骤操作，都能推演出最终真相：

### 第一步：模型性能审计与盲点发现 (对应 Q1)
**面临挑战**：YOLO 模型给了成千上万个目标检测框，但其中存在极高的假阳性（将杂物错认为目标）和假阴性（漏检）。
**系统动作**：我们首先利用系统中的**目标检测置信度分布图**对原始 CSV 文件进行聚合分析。
**分析过程**：通过对原始检测数据的置信度分数分布进行可视化，我们发现像 `person`、`car` 这样的常规大物体，模型表现稳定（高置信度密集）；但对于赛题重点怀疑的小型物件（如铅笔、气球、硬币等），置信度分布极其离散，大量低置信度噪点充斥其中。
**结论**：机器预测不能直接作为证据，必须依靠“人在回路（Human-in-the-loop）”进行降噪与二次标注。

### 第二步：人工辅助与标签误差校正 (对应 Q2)
**面临挑战**：如何高效清洗成千上万张图片中的误报？
**系统动作**：系统提供了 **Misclassification Correction 面板（图片误分类校正画廊）**。
**分析过程**：用户可以在该组件中选择特定的疑似物品（如 `blueSunglasses`、`canadaPencil`），系统将从 `raw_data` 目录直接拉取并平铺所有被模型标记为该物品的原图与边框。调查员可通过视觉快速核查，剔除由于形状或颜色相近导致的荒谬误报（例如把桌腿识别为铅笔）。
**结论**：通过系统化的排查，我们生成了一份高纯度的数据字典（项目代码中的 `human_corrections.json`），大幅剔除了干扰项，为后续关系推演奠定了坚实的数据底座。

### 第三步：人-物关系矩阵映射与过滤 (对应 Q3)
**面临挑战**：数据干净后，如何判断哪些物品是日常随处可见的杂物，哪些才是专属的“暗号”？
**系统动作**：引入 **矩阵差异对比图 (Matrix Delta Bars) 与 特征分布热力图**。
**分析过程**：我们在图表中横向排列 40 名涉案人员，纵向排列所有清洗后的有效物品类别。通过矩阵点的密集度（发生频次），能够一眼看出某些物品（如手机、杯子）被几乎所有人高频使用（泛化特征），而某些物品（如 `cactusPaper`、`yellowBalloon`）仅被特定的一小撮人（5-6人）紧密共享。
**结论**：我们借此排除了“大众物品”，将怀疑范围急剧缩小到了具备“群体排他性”的少数几个候选暗号群体上。

### 第四步：多维评分与力导向关系网破局 (对应 Q4)
**面临挑战**：在最后剩下的几个高度可疑物品（如 `canadaPencil`、`rainbowPens`、`noisemaker` 等）中，究竟哪一个才是唯一的 8 人组暗号？
**系统动作**：利用 **候选暗号综合评分雷达图 (Candidate Ranking Radar)** 与 **实体关联力导向网络图 (Force-Directed Graph，基于 D3.js)**。
**分析过程**：
1. 雷达图从三个正交维度（全局稀有度、局部内聚度、交互对称性）对所有候选物品进行量化打分。`canadaPencil` 在“交互对称性”（即双向通信确认）上得分最高。
2. 随后，我们在力导向图中注入校正后的数据。将过滤阈值调高，剔除弱连接。当焦点锁定在 `canadaPencil` 节点时，力导向图的引力模型自动将所有关联的人员和图片吸附成一个独立的闭环聚类（Cluster）。
**结论**：关系网清晰地剥离出了一个极其纯粹的群体拓扑：正好有 **8 名特定成员**（Person 4, 7, 14, 15, 22, 25, 35, 39）。这 8 人与 `canadaPencil` 产生了强烈的星型结构连接，且完全符合赛题中“特定暗号只属于特定 8 人”的假设。

### 第五步：多模态证据流固化 (对应 Q5)
**面临挑战**：数据推演出的 8 人名单，如何转化为无可辩驳的视觉与通信证据？
**系统动作**：进入 **多模态证据画廊 (Evidence Photo Gallery) 与 暗号流动图** 面板。
**分析过程**：在这个终极组件中，系统按人员列出了这 8 人网络中的确切 31 张图像证据。用户可以直观地观察到，这些人在不同的场景下，刻意地将一把带有枫叶标志的加拿大铅笔摆放在画面显眼处（甚至包括文字中的刻意提及与暗示），作为他们向同伙发出行动指令或安全确认的标志。
**结论**：至此，证据链实现完美闭环。我们彻底证实了 `canadaPencil` 是该组织的联络图腾，并精准抓获了核心的 8 名犯罪嫌疑人，完整解答了赛题的终极挑战。

## 核心图表组件架构与代码映射

为了实现上述思路，前端应用（Vue 3 + ECharts + D3.js）与后端服务（Python Flask）进行了深度解耦设计：

1. **`ForceDirectedGraph.vue` (力导向网络组件)**
   - **作用**：解析 `graphCorrected.json`，使用 D3.js 构建引力模型。它是第四步剥离 8 人拓扑结构的核心。通过交互式的节点拖拽与过滤阈值滑动，动态隐藏无关的干扰边。
2. **`MatrixDeltaBars.vue` (矩阵差异对比图)**
   - **作用**：直观展示原始检测（高误报）与人工校正后（低误报）的特征数量衰减。用于 Q3 的物品泛化度分析。
3. **`CandidateRankingChart.vue` (候选评分图表)**
   - **作用**：利用 ECharts 实现雷达或多维条形图，量化提取暗号的数学特征（稀有性、高频共现性），支撑 Q4 的唯一性决策。
4. **`EvidencePhotoGallery.vue` (多模态图片证据流)**
   - **作用**：连接前端 UI 与 `raw_data/MC2-Image-Data` 的桥梁。接收来自关系网的节点点击事件，下钻拉取原图文件及 `caption.txt` 语义描述，提供定谳依据（Q5）。
5. **后端 `analysis_engine.py` (分析引擎)**
   - **作用**：提供高效的 DataFrame 内存级运算，聚合 YOLO 原始 CSV 的边界框置信度，为前端的 Q1 分布图提供宏观聚合数据。

## 部署与使用指南

**1. 准备运行环境**
系统依赖 Python 3.9+ 处理数据服务，依赖 Node.js 16+ 构建前端交互大屏。

**2. 启动数据分析后端**
进入 `backend_service` 目录，安装依赖并启动 Flask 服务，该服务将负责分发 `raw_data` 中的图片、文本及聚合统计数据。
```bash
cd backend_service
pip install -r requirements.txt
python app.py
```
*(后端服务默认运行在 http://localhost:5000)*

**3. 启动可视分析系统大屏**
新开一个终端窗口，进入 `frontend_client` 目录启动 Vite 引擎。
```bash
cd frontend_client
npm install
npm run dev
```
*(启动成功后，在浏览器中访问 http://localhost:5173 即可进入交互界面)*
