# VAST Challenge 2020 Mini-Challenge 2: 异常通信行为可视分析系统

## 📖 项目背景

在复杂的多媒体社交网络中，犯罪分子往往通过隐藏在图片和文本中的“暗号（Totem）”进行秘密通信。本可视分析系统针对 VAST Challenge 2020 Mini-Challenge 2 的应用场景设计。我们的目标是通过对社交网络中的图像内容（YOLO目标检测数据）和文本消息进行综合关联分析，找出在公司内部利用特定暗号进行秘密通信的 8 人嫌疑子群体，并揭示他们的核心通信媒介。

本项目结合了**多模态数据特征融合**、**AI模型审计与误差校正**以及**复杂网络图挖掘**技术，提供了一套端到端的可视分析流水线。

---

## 🔍 分析思路与核心流水线

为了从成千上万条含有噪声的模型预测记录中挖掘出真实的 8 人嫌疑群体，本系统遵循了以下渐进式可视分析流水线：

1. **宏观感知与特征扫描 (Macro Exploration)**：全景式浏览物体出现频率，寻找那些“分布异常、少数人高频使用”的候选暗号物品。
2. **AI模型审计与校正 (Model Auditing & Correction)**：利用可视化交互手段，核查 YOLO 目标检测模型的高置信度误报与漏报，通过人机协同纠正特征数据。
3. **关系重构与群落发掘 (Network Reconstruction)**：将清洗后的数据映射为“人-物”异构图，通过力导向布局挖掘出联系紧密的嫌疑子图。
4. **证据固化与线索追踪 (Evidence Triangulation)**：在详细的仪表盘中查阅人物的图片证据流与文本语义，最终锁定嫌疑群体。

---

## 📊 核心图表组件与结论解析

### 1. 目标检测置信度分布图 (Confidence Distribution View)
- **组件含义**：通过小提琴图或箱线图，展示 YOLO 预测模型在不同类别物品上的置信度得分分布情况。
- **分析过程**：我们在分析中发现，由于原始图片的拍摄角度、光照和被遮挡情况复杂，模型对某些小型物品（如铅笔、特定饰品等）的置信度极不均匀，存在大量假阳性（误报）现象。
- **阶段结论**：揭示了原始机器推理的不可靠性，强调了引入人在回路（Human-in-the-loop）进行视觉校正的必要性。

### 2. 人-物特征矩阵与差异对比图 (Matrix Delta Bars)
- **组件含义**：双向对比条形图，对比“原始预测”与“人工校正后”每个类别对应的具体拥有人数。横向代表数量变化，纵向代表物品类别。
- **分析过程**：通过对那些潜在的候选暗号（如彩虹笔、噪音制造器、魔方、加拿大铅笔等）进行筛查比对，该组件清晰地反映出哪些物品是由于模型过拟合导致的广泛误报。
- **阶段结论**：通过校正，我们淘汰了那些泛化性过强、被多数人持有的物品。最终发现，具备极强排他性（仅属于特定极少数群体）的物品类别收敛到了少数几个特征物上。

### 3. 候选暗号综合评分雷达图 (Candidate Totem Ranking Radar)
- **组件含义**：多维雷达图（或平行坐标轴），基于三个维度（物品稀有度、群体内聚度、图文共现率）对候选暗号进行综合评分排序。
- **分析过程**：我们对筛选出的嫌疑物品进行打分。一个真正作为暗号的物品，既要在全局中具有稀有性（不能是日常随处可见的），又必须在嫌疑群体中具有高度覆盖率，并且发送方和接收方都有规律性的交互。
- **阶段结论**：多维评分最终将 `canadaPencil`（加拿大枫叶铅笔）推至评分榜首，确立其为此次秘密通信的核心暗号。

### 4. 实体关联力导向网络图 (Entity Force-Directed Graph)
- **组件含义**：将人员（Person）、图片（Image）与被检测出的特征物件（Object）映射为一张庞大的异构关系网。节点大小代表关联度，颜色区分实体类型。
- **分析过程**：在未校正数据中，关系图呈现极度发散和混乱的“毛线团”状态；而在加载了校正数据过滤后，网络图自动收敛。我们选中焦点物品（如 `canadaPencil`）时，系统高亮了与该物品直接交互的所有子节点。
- **阶段结论**：在排除了无用特征和误报连接后，关系网中清晰地剥离出了一个完美闭环的 8 人联络拓扑图，这 8 人通过携带此特定暗号的图片进行高频双向通信。

### 5. 多模态证据时间轴与图片画廊 (Evidence Photo Gallery)
- **组件含义**：用于最终证据链闭环的精细查看面板。支持点击特定成员，展示其名下相关联的照片阵列，并配以文本摘要提取。
- **分析过程**：为了给最终的 8 人嫌疑犯名单定性，我们在该面板中加载了网络图挖掘出的最终目标人员。通过详细的网格状画廊排布，我们直观核实了该群体发布的 24 张含有 `canadaPencil` 的关键通信照片。
- **阶段结论**：照片视觉证据与前期数据逻辑推演完美咬合，彻底锁定了 Person 3, 4, 7, 14, 23, 29, 32, 39 等 8 人正是我们要找的秘密通信小队。

## 🛠 技术栈

*   **前端可视化**：Vue 3, ECharts (用于统计图与矩阵比较), D3.js (用于高定制化的力导向关系网络), Vite
*   **后端支撑**：Python, Flask (轻量级数据接口与状态管理)
*   **数据处理**：Pandas, NumPy (针对海量目标检测 CSV 文件与 JSON 进行快速特征清洗与合并)

## 🚀 快速启动

1. **环境准备**
   请确保您的系统已安装 Python 3.9+ 与 Node.js 16+。

2. **启动后端数据分析服务**
   ```bash
   cd backend_service
   pip install -r requirements.txt
   python app.py
   ```

3. **启动前端可视化系统**
   ```bash
   cd frontend_client
   npm install
   npm run dev
   ```

4. **访问系统**
   在浏览器中打开命令行提示的本地端口（如 `http://localhost:5173`），即可进入可视分析系统大屏。
